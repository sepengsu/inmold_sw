20261030 광량 강건성 실험

1. 바탕화면/20261030_빛강건성_실험/src/ 안의 '20261030_빛강건성_일반시편.cmd'를 실행합니다.
2. 일반 시편을 고정한 상태로 완료될 때까지 시편/촬영 설정을 바꾸지 않습니다.
3. 시편을 검증시편으로 교체한 뒤 '20261030_빛강건성_검증시편.cmd'를 실행합니다.
   검증시편 실행은 프로젝트의 certification(국소) 모드를 사용합니다.
   일반 모드로 검사할 검증시편은 --specimen 검증시편 --mode normal 옵션을 사용합니다.

전체 조합: 100, 75, 50, 25, 0%의 4요인 완전조합, 시편당 625조건.
실행/이름 순서: 좌측 판조명 / 우측 판조명 / 좌측 바조명 / 우측 바조명.
채널: CH1+2 / CH5+6 / CH3 / CH4.
프로젝트 API의 배열 순서는 좌판/좌바/우바/우판이므로 코드에서 변환합니다.
파일명에 * 문자를 사용할 수 없어 조건을 100_100_100_75 형식으로 표기합니다.
예: 스크린샷/일반시편_100_100_100_75.png

결과: 바탕화면/20261030_빛강건성_실험/

  20261030_빛강건성_실험.xlsx         시편별 시트, 디자인 서식 없는 숫자 데이터

엑셀은 정확히 7열입니다.
광량변화조건, P1 함침률(%), P1 신뢰도(%), P2 함침률(%), P2 신뢰도(%), P3 함침률(%), P3 신뢰도(%)
값은 % 단위의 0~100 숫자입니다. 표시 반올림 없이 원본 값을 기록합니다.
신뢰도는 각 측정 픽셀에서 선택된 이진 분류의 확률(p 또는 1-p)의 평균 × 100입니다.
3클래스 모델에서는 기존 함침률 계산과 동일하게 Exposure+Weldline을 양성으로 합칩니다.
신뢰도는 정답 대비 정확도나 보정된 통계적 신뢰구간이 아닙니다.
검증 모드는 함침률과 동일한 원본 비검정 픽셀만 신뢰도에 포함합니다.

조명 변경마다 CH1~6의 ACK를 모두 확인하고, 최소 1초 또는 노출 2회+0.5초 중 더 긴 시간 동안 안정화합니다.
카메라 노출/게인/ROI 기준/모델은 실험을 위해 자동 조정하지 않습니다.
어두운 조건 등으로 측정이 실패하면 해당 조건의 UI 오류 화면을 저장하고 6개 숫자 셀은 빈칸으로 둡니다.
구체적인 오류는 measurements.jsonl에 있습니다. 조명 ACK/장비/서버/파일 저장 오류는 실험을 중단합니다.
엑셀은 첫 조건, 10조건마다, 종료 시 저장하고 모든 조건은 JSONL에 즉시 저장합니다.
실험 중에는 엑셀 결과 파일을 닫아 두세요.

중단: 실행 창에서 Ctrl+C 또는 결과 폴더에 확장자 없는 STOP 파일을 만듭니다.
재개: STOP 파일을 직접 정리한 뒤 같은 실행 파일을 다시 실행하면 완료 조건을 건너뜁니다.
실패 조건 재측정: 실행 파일에 --retry-failed 옵션을 붙입니다.
강제 종료/정전 시: .experiment.lock의 PID가 실행 중이 아닌지 확인 후 해당 잠금 파일을 직접 정리합니다.
엑셀 복구: 실행 파일에 --export-only 옵션을 붙이면 장비 조작 없이 JSONL에서 재생성합니다.
동일 시편 이름에 다른 모드/노출/ROI 설정을 혼합할 수 없습니다. 새 시편은 --specimen 새이름을 사용합니다.

정상 종료/중단/오류 시 프로젝트에 저장된 조명 설정을 전송하여 복원합니다.
컨트롤러는 실제 이전 밝기를 읽어올 수 없으므로 저장값 복원입니다.
강제 프로세스 종료/전원 차단 시에는 복원이 실행되지 않을 수 있습니다.
실험 중에는 촬영 대상과 비전 UI/조명 컨트롤러를 다른 작업에서 조작하지 마세요.
